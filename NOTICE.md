## This fork has been changed

Hangover started from Open Island as it stood on 2026-09-15 (upstream
commit `b50f87a`, version 1.2.1). It has been changed since 2026-10-07.
This notice was written on 2026-10-09.

The changes include the Nook page and its widgets, the welcome tour, the
status glow, the new name and the `hangover://` link scheme. The git
history of this repository lists every change, its date and its author.
